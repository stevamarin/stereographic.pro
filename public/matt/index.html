The Build

How I built the systems that run the agency.

A practitioner's log from the intersection of content production and AI. I run a B2B video agency. I also built the AI agents that help run it. This is the unfiltered account of what I'm building, why it works, and what broke first.

The Fleet

Agents in production

These are the autonomous systems currently running in our operation. Each one replaced a process that used to require a human.

intake-agent Client Intake Agent

Handles the first 48 hours of any new project. Collects requirements, asks clarifying questions, and produces a structured brief. Zero human touch until kickoff.

brief-processor Brief Processor

Takes raw client briefs and converts them to our internal production format. Flags ambiguities and missing info before it reaches the team.

caption-agent Caption Agent

Auto-transcription, formatting, and caption file generation. Processes deliverables without a producer touching the file.

report-agent Weekly Report Agent

Generates client-facing progress reports from our project management data every Friday. 8 hours of producer time saved weekly.

Architecture

How it's built

Everything runs on a stack I chose for longevity over novelty. The goal was something our team could maintain and I could extend.

// Agent stack — as of Q1 2026
{
  orchestration:  "Claude API (claude-opus-4-6)",
  triggers:       "n8n self-hosted",
  data:           "Airtable + Postgres",
  comms:          "Slack + email webhooks",
  auth:           "Internal API keys per agent",
  hosting:        "Hetzner VPS (Serbia)"
}

No LangChain. No vendor lock-in. Plain API calls with structured prompts, retry logic, and human escalation paths for anything above a confidence threshold.

The story

From Belgrade to Daytona

I grew up in Serbia with an early obsession with how things work — not just the output, but the systems underneath. That instinct drove me to media production, then to running a studio, then, eventually, to building the infrastructure that makes the studio run.

DME Studio started as a one-person operation doing scrappy B2B video work. It grew into a 10-person agency producing content for companies across North America and Europe — with teams operating out of Daytona Beach and Belgrade simultaneously. We figured out how to make that work.

A few years in, I started building automation into our operations — not because it was fashionable, but because the alternative was hiring my way through every bottleneck. I'm a builder by instinct. When something breaks or slows down, I'd rather redesign the system than add more people to the broken one.

Why did you start building agents?
The honest answer: I got tired of doing the same things twice. Client intake, project briefs, status updates, caption processing — work that was necessary but mechanical. In 2023, I started building agents to handle that layer. By the end of 2024, our operations ran differently.
This isn't a pivot or a rebrand. DME Studio still makes B2B video. But I now run it with AI infrastructure I built myself, and I think that changes what's possible for a small team.
What's life like outside the work?
I live in Daytona Beach with my family. I'm drawn to things that reward patience — building systems, long-form reading, learning how adjacent fields solve problems I have. Most of what I've learned about operations, I learned from manufacturing, not media.
What drives all of this?
Small teams shouldn't have to choose between scale and quality. That's the thesis. I believe a 10-person operation can do work that used to require 40 people — if the systems are right. I'm building those systems. The Build Log is how I share what I learn.
